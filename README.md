A deterministic Python program (standard library only) that writes exactly one word — **dimah1109** — to `/output/entry.txt`. Entry for make.fun's "One Word, One Username, One Reward" bounty ($5).

## The word

**dimah1109** — the entrant's own make.fun username (@dimah1109). The judge's first criterion is that the entry is a real make.fun username, the entrant's own handle sent as one word; any invented word loses to a genuine handle, so the honest entry is the handle itself, exactly as registered. Nine characters, one word, no spaces, no padding: "dimah" reads as a name, "1109" hangs off it like a date or a code — a handle that sticks after one look and sounds like one its owner would happily wear.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

No network, no randomness, no clock: two runs write byte-identical output. The entry is exactly 9 UTF-8 characters, inside the 1–30 gate.
